# Machine Learning Mini Practice Projects 🤖📊

Welcome to the **Machine Learning Mini Practice Projects** repository! This repository contains a collection of beginner to intermediate-level Machine Learning projects. Each project is implemented using Python and Jupyter Notebooks, focusing on different ML algorithms, data preprocessing techniques, and evaluation metrics.

## 💡 About the Repository
This repository serves as a practical playground to understand and apply various Machine Learning concepts. It covers both **Regression** and **Classification** problems using classic datasets. It is highly recommended for anyone looking for reference code or wanting to understand step-by-step implementations of ML models.

---

## 🚀 Projects Included

Here is a brief overview of the projects available in this repository:

1. **[Breast Cancer Prediction](./Breast_Cancer_Prediction/)**
   - **Type:** Classification
   - **Objective:** Predicts whether a breast mass is malignant or benign based on diagnostic measurements.
   
2. **[Diabetes Prediction](./Diabetes_Prediction/)**
   - **Type:** Classification
   - **Objective:** Predicts whether a patient has diabetes based on certain diagnostic parameters like BMI, insulin levels, and age.

3. **[House Price Prediction](./House%20Price%20Prediction/)**
   - **Type:** Regression
   - **Objective:** Estimates the pricing of houses based on features like area, number of rooms, and location.

4. **[Linear Regression](./Linear_Regression/)**
   - **Type:** Regression
   - **Objective:** A foundational practice project focusing purely on the mechanics and application of simple/multiple Linear Regression models.

5. **[Loan Prediction Model](./Loan-Prediction-Model/)**
   - **Type:** Classification
   - **Objective:** Automates the loan eligibility process by predicting whether a loan should be approved or rejected based on applicant details.

6. **[New York Taxi Trip](./New%20York%20Taxi%20Trip/)**
   - **Type:** Regression / Time-Series
   - **Objective:** Analyzes and predicts New York taxi trip durations or fare amounts based on pickup/dropoff coordinates and timestamps.

7. **[Sonar vs Rock (Mine Prediction)](./Sonar%20vs%20Rock/)**
   - **Type:** Classification
   - **Objective:** Classifies sonar returns to differentiate between a metal cylinder (mine) and a roughly cylindrical rock.

8. **[Telecom Customer Churn](./Telecom-Customer-Churn/)**
   - **Type:** Classification
   - **Objective:** Predicts whether a telecom customer is likely to churn (leave the network) based on their usage metrics and account details.

## 🛠️ Technologies & Libraries Used

All projects are entirely written in **Jupyter Notebook (100%)**. The primary tech stack includes:
- **Language:** Python 3.x
- **Data Manipulation:** Pandas, NumPy
- **Data Visualization:** Matplotlib, Seaborn
- **Machine Learning:** Scikit-Learn (Logistic Regression, Random Forest, SVM, XGBoost, etc.)
- **Environment:** Jupyter Notebook

## ⚙️ How to Run the Projects

To explore these projects on your local machine, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/Atharva-Gawas456/Machine-Learning-Mini-Practice-Projects.git](https://github.com/Atharva-Gawas456/Machine-Learning-Mini-Practice-Projects.git)
   ```
2. **Navigate to the directory:**
  ```Bash
  cd Machine-Learning-Mini-Practice-Projects
  ```
3. **Install the required libraries (If you don't have them installed):**

  ```Bash
  pip install pandas numpy scikit-learn matplotlib seaborn jupyter
  ```
4. **Launch Jupyter Notebook:**

  ```Bash
  jupyter notebook
  ```
5. **Navigate to the desired project folder in the Jupyter interface and open the .ipynb file to view the code, run the cells, and see the visualizations.**
